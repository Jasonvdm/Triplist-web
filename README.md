# Triplist-web

Static landing page for Triplist, served from this repo (`index.html`, `_config.yml`, `CNAME`).

> The newer marketing/SEO website prototype lives in the separate [web](https://github.com/Triplist-Ai/web) repo — check which one your task actually targets.

## Implementation Plans

Implementation plans for this repo live in the shared **[Triplist-Ai/plans](https://github.com/Triplist-Ai/plans)** repo, not here. Every Triplist repo (Triplist-iOS, web, admin, atlas, atlas_viewer, db) shares it so plans stay discoverable regardless of which repo the work lands in.

```bash
git clone git@github.com:Triplist-Ai/plans.git ~/Development/triplist/plans
```

One markdown file per plan, kebab-case and descriptive of the feature (e.g. `website-migration-to-vercel.md`), with the date and target repo(s) at the top. Pull before writing; commit and push when done.
