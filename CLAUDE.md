## Implementation Plans

Implementation plans do **not** go in this repo. They live in the shared **[Triplist-Ai/plans](https://github.com/Triplist-Ai/plans)** repo, cloned locally at `~/Development/triplist/plans`, which every Triplist repo shares.

One markdown file per plan, kebab-case and descriptive of the feature, with the date and target repo(s) at the top. Pull before writing; commit and push when done. Full conventions: the "Implementation Plans" section of [README.md](README.md).
